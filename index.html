🌳 Cây Phụ Thuộc Khóa Ngoại (Foreign Key Insertion Hierarchy)
Quy tắc toàn vẹn dữ liệu

Khi thêm dữ liệu (INSERT), bắt buộc phải chèn vào các bảng cha (Parent Tables) trước. Nếu chèn vào bảng con khi chưa có dữ liệu tham chiếu ở bảng cha, hệ quản trị MySQL sẽ từ chối và báo lỗi Error Code: 1452.

⚠️ Lỗi thường gặp:

  • Chèn điểm thi của học sinh mã số 99 khi trong bảng Student chỉ mới có mã 1, 2, 3.
  • Chèn lớp học với tên bị để trống trong khi cột ClassName được đặt thuộc tính NOT NULL.
  • Chèn điểm số nhỏ hơn 0 hoặc lớn hơn 100 vi phạm ràng buộc kiểm tra CHECK (Mark BETWEEN 0 AND 100).

🔍 Báo Cáo Kết Quả Học Tập (INNER JOIN 4 Bảng)
SELECT s.StudentID, s.StudentName, c.ClassName, sub.SubName, sub.Credit, m.Mark AS DiemThi, m.ExamTimes AS LanThi FROM Mark m INNER JOIN Student s ON m.StudentId = s.StudentID INNER JOIN Class c ON s.ClassId = c.ClassID INNER JOIN Subject sub ON m.SubId = sub.SubId ORDER BY s.StudentID ASC, sub.SubName ASC;

💻 Mã Nguồn SQL Đầy Đủ (DDL + DML + Truy Vấn) 
-- Bước 0: Tạo CSDL QuanLySinhVien
DROP DATABASE IF EXISTS QuanLySinhVien;
CREATE DATABASE QuanLySinhVien CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- Bước 1: Kích hoạt CSDL
USE QuanLySinhVien;

-- 1. Bảng Class
CREATE TABLE Class (
    ClassID   INT AUTO_INCREMENT NOT NULL,
    ClassName VARCHAR(60) NOT NULL,
    StartDate DATETIME NOT NULL,
    Status    BIT DEFAULT 1,
    CONSTRAINT PK_Class PRIMARY KEY (ClassID)
) ENGINE = InnoDB;

-- 2. Bảng Student
CREATE TABLE Student (
    StudentID   INT AUTO_INCREMENT NOT NULL,
    StudentName VARCHAR(30) NOT NULL,
    Address     VARCHAR(50),
    Phone       VARCHAR(20),
    Status      BIT DEFAULT 1,
    ClassId     INT NOT NULL,
    CONSTRAINT PK_Student PRIMARY KEY (StudentID),
    CONSTRAINT FK_Student_Class FOREIGN KEY (ClassId) 
        REFERENCES Class(ClassID) 
        ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE = InnoDB;

-- 3. Bảng Subject
CREATE TABLE Subject (
    SubId   INT AUTO_INCREMENT NOT NULL,
    SubName VARCHAR(30) NOT NULL,
    Credit  TINYINT NOT NULL DEFAULT 1 CHECK (Credit >= 1),
    Status  BIT DEFAULT 1,
    CONSTRAINT PK_Subject PRIMARY KEY (SubId)
) ENGINE = InnoDB;

-- 4. Bảng Mark
CREATE TABLE Mark (
    MarkId    INT AUTO_INCREMENT NOT NULL,
    SubId     INT NOT NULL,
    StudentId INT NOT NULL,
    Mark      FLOAT DEFAULT 0 CHECK (Mark BETWEEN 0 AND 100),
    ExamTimes TINYINT DEFAULT 1,
    CONSTRAINT PK_Mark PRIMARY KEY (MarkId),
    CONSTRAINT FK_Mark_Subject FOREIGN KEY (SubId) 
        REFERENCES Subject(SubId) ON DELETE CASCADE ON UPDATE CASCADE,
    CONSTRAINT FK_Mark_Student FOREIGN KEY (StudentId) 
        REFERENCES Student(StudentID) ON DELETE CASCADE ON UPDATE CASCADE
) ENGINE = InnoDB;
